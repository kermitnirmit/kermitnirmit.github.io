FF Commish

A commissioner's toolkit for Sleeper fantasy leagues: power rankings, survivor and a record book.

Next.jsTypeScriptPostgresSleeper API

Every fantasy league has a commissioner who writes the weekly power rankings. FF Commish gives them a home for it. Paste in a Sleeper league ID and you get shareable rankings plus a set of league pages built from Sleeper's data. I built it with a friend.
